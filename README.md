# Building a Minimal AI Agent

A hands-on engineering project exploring how AI agents work, from fundamental execution mechanisms to more reliable architectures, using **Python** and **.NET/C#**.

The goal is to understand what happens behind agent frameworks by implementing, testing, and progressively improving a working AI agent.

Each chapter focuses on a specific engineering challenge, combining practical code, technical explanations, and reproducible experiments.

## What You will learn

Throughout this project, we'll explore:

* **Agent Execution Loops** - how agents execute tasks and determine when to stop.
* **LLM Integration** - how language models interact with application logic.
* **Tool Calling** - how language models request and execute external operations.
* **State Management** - how execution context is maintained across steps.
* **Error Handling** - how to manage failures, timeouts, and execution limits.
* **Testing & Observability** - how to verify and inspect agent behavior.
* **Engineering Trade-offs** - how architectural decisions differ between Python and C#.
